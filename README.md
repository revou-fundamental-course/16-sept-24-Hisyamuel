# Personal Web Portfolio - Nur Amali Hisyam 🚀

Selamat datang di repositori Web Portfolio pribadi saya! Website ini dibangun untuk menampilkan perjalanan karir, keterampilan teknis, proyek-proyek yang telah saya kerjakan, serta sertifikasi yang saya peroleh sebagai seorang **Front-End Developer**.

🔗 **Live Website:** [nuramalihisyam.netlify.app](https://nuramalihisyam.netlify.app/)

---

## ✨ Fitur Utama (Key Features)

Website ini dirancang dengan fokus pada **User Experience (UX)** dan **User Interface (UI)** yang modern, bersih, dan interaktif:

- 📱 **Fully Responsive Design:** Tampilan yang beradaptasi dengan sempurna di semua perangkat (Desktop, Tablet, dan Smartphone) menggunakan arsitektur CSS Flexbox dan Grid. Dilengkapi dengan *Hamburger Sidebar Menu* untuk navigasi mobile.
- 🌓 **Dark Mode / Light Mode Toggle:** Fitur pergantian tema yang menyimpan preferensi pengguna menggunakan `LocalStorage`, memberikan kenyamanan visual (menggunakan palet warna *Deep Navy* untuk mode gelap).
- ♾️ **Infinite Marquee Scroll:** Animasi berjalan otomatis tanpa putus (infinite loop) pada bagian *Tech Stack* dan *Certifications*. Animasi ini dilengkapi fitur *pause-on-hover* untuk memudahkan interaksi pengguna.
- 🍱 **Bento Grid Layout:** Menampilkan daftar proyek dalam tata letak *Bento Grid* bergaya modern dengan efek *glassmorphism* dan overlay interaktif saat di-hover.
- ⏳ **Experience Timeline:** Garis waktu (timeline) vertikal yang melacak riwayat pengalaman profesional dan program studi independen secara rapi.
- 🔔 **Custom Notification & Greeting:** Pop-up sapaan awal saat website dimuat dan sistem notifikasi *Toast* kustom saat mengirim pesan.

---

## Struktur Konten (Sections)

Website ini terdiri dari satu halaman utama (Single Page) yang terbagi menjadi beberapa *section* berikut:

1. **Hero / Home:** Bagian penyambutan dengan tipografi besar, animasi mengambang (floating animation) pada foto profil, serta tautan langsung ke media sosial (Instagram, LinkedIn, GitHub).
2. **About Me:** Deskripsi singkat mengenai latar belakang saya sebagai mahasiswa Sistem Informasi dan visi saya dalam dunia Front-End Development.
3. **Education:** Kartu informasi mengenai latar belakang pendidikan formal.
4. **Experiences:** Daftar riwayat pengalaman yang disajikan dalam bentuk *Timeline*, termasuk pengalaman *Freelance* dan keikutsertaan dalam *Cohort* terkemuka.
5. **Tech Stack:** Deretan teknologi, *framework*, dan *tools* yang saya kuasai (HTML, CSS, JavaScript, Tailwind, Node.js, PostgreSQL, Figma, dll.) yang ditampilkan menggunakan *Infinite Slider*.
6. **Projects:** Pameran karya aplikasi/website yang telah saya kembangkan, seperti *Biography Blog*, *Bookshelf App*, *Notes App*,*Story App*, *SkillRad*, *Cli-matez*, dan lain-lain.
7. **Certifications:** Galeri sertifikat kelulusan dari berbagai platform pembelajaran seperti Dicoding, RevoU, Alison, MySkill, dan HariSenin.
8. **Message Me:** Formulir kontak interaktif yang terhubung dengan email pribadi saya dengan memunculkan sistem notifikasi *Toast* saat pesan dikirim untuk memudahkan pengunjung menghubungi saya secara langsung.
9. **Footer:** Navigasi cepat (Quick Nav) dan kontak detail.

## Teknologi yang Digunakan (Built With)

Proyek ini dibangun dari awal (scratch) tanpa menggunakan framework CSS berat, untuk memaksimalkan performa dan mengasah pemahaman mendalam tentang dasar-dasar web:

- **HTML5:** Struktur semantik web.
- **CSS3:** Penggunaan Custom Variables (`:root`), Flexbox, CSS Grid, Keyframes Animations (Marquee, Float, Morphing), dan Media Queries untuk responsivitas.
- **Vanilla JavaScript:** Manipulasi DOM, penanganan *Event Listener*, interaksi form, dan pengelolaan `LocalStorage` untuk tema.
- **Phosphor Icons:** Pustaka ikon pihak ketiga untuk UI yang elegan.
- **Netlify:** Platform *hosting* dan *deployment* yang cepat dan terintegrasi.
